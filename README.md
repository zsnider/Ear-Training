# Ear Training
Audio ear training games with custom settings. Train your ear.
Upload your own music or audio loops to play the games. Or use pink noise by default. I recommend adding a folder without too many tracks to avoid long upload times. Try ~10-20 tracks at first. Any audio file should work (.mp3, .wav, etc.)

EQ Match is a game to match an equalizer with custom settings. 

Compressor is a game to match compression settings.
